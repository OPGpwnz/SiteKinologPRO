# QA-отчет PITFLY

## Отмечено в аудите

- Основной интерфейс находится в `index.html`.
- База данных и Supabase не подключены; данные хранятся в `localStorage`.
- В проекте нет реальной серверной авторизации.
- Бренд PITFLY обновлен в основном интерфейсе и проектных JSON-файлах.
- Логотип подключен в шапку и подвал.
- Прайс-лист содержит услуги из мастер-брифа.
- Отмена для клиента блокируется менее чем за 5 часов до занятия.
- Абонементы получают срок действия 45 дней при активации.

## Найденные и исправленные конфликты

- Устаревший файл `project/golden-template.html` с контентом «Кинолог PRO» удален.
- Расчёт дохода админки переведен с устаревшей суммы 1200 ₽ на абонемент PITFLY стоимостью 7500 ₽.
- Скругления интерфейса приведены к диапазону 0–4 px для основных контейнеров.
- Светлая поверхность рассылки заменена на темную панель в цветовой системе PITFLY.
- Для демонстрационной записи в старте теперь сохранён код услуги `subscription`.
- Продление абонемента больше не использует просроченный абонемент как активный.
- Вход и регистрация по email и паролю заменили Magic Link/OTP; профиль клиента создаётся SQL-триггером после применения миграции.

## Не реализованные области мастер-брифа

- Полная базовая SQL-схема и комплект RLS-политик не оформлены миграциями в репозитории.
- Автоматические уведомления отсутствуют.
- Повторяющееся расписание автоматически не создаётся; слоты генерируются на выбранный период вручную.
- Покупка абонемента через онлайн-запись пока не подключена.
